# DailyBrief

DailyBrief is an open-source iOS application that helps professionals
discover the five most important articles in their selected field.

## Problem

Professionals spend too much time searching multiple sources and deciding
what is worth reading.

## MVP

The user can:

1. View today's digest containing five articles.
2. See a concise summary and why each article matters.
3. Open the original article.
4. Save an article for later.
5. Browse the application offline.

## First vertical slice

The application loads a bundled JSON fixture and displays a daily digest.
