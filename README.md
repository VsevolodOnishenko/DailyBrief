# DailyBrief

An open-source iOS application that presents five concise professional
articles per day.

## Current state

The first vertical slice loads a bundled daily digest and displays it
using a repository-based architecture.

## Tech stack

- Swift 6.3
- SwiftUI
- Observation
- Swift Concurrency
- Swift Testing

## Next milestone

Load the daily digest from a remote API while preserving the bundled
repository for previews, tests, and offline fallback.
